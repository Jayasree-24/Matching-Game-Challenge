# Matching-Game-Challenge
A simple and interactive Memory Card Game built using HTML, CSS, and JavaScript. The player flips two cards at a time and tries to find all matching pairs with fewer moves.

## 🎮 Features

- 🃏 Randomly shuffled cards
- 🔊 Flip, match, wrong-match, and winning sounds
- 🏆 Score tracking
- 🔢 Move counter
- 🔄 Restart game
